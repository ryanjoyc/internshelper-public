# Role-fit profile

The `review-internships` and `deep-scan-source` skills use this profile when judging a job
description. Copy this file to `config/profile.md`, then replace the prompts below with your own
criteria. The populated file is ignored by Git.

**Background:** List the experience, coursework, technical areas, and tools that should count as
evidence of fit. Keep this broad enough to catch roles whose titles are unusual.

**Interests:** List the role families, domains, work styles, and company types you want to see.

**A role fits if:** Describe the work you would seriously consider. Judge the job description,
not title keywords alone.

**A role does not fit if:** Describe clear exclusions such as senior-only or non-technical work.

**Hard gates:** List any term, graduation-window, location, work-authorization, or level rules that
must hold. Leave a category out when it is not a hard requirement.
